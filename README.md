
## 📚 Branch de Exercícios
Esta branch é destinada para o envio dos exercícios resolvidos.  
Siga as instruções abaixo para submeter seus exercícios corretamente.

---

## 🚀 Como submeter seus exercícios

### 1. Criar uma nova branch
Primeiro, certifique-se de estar na branch `exercicios`:

```bash
git checkout exercicios
git pull origin exercicios
```

### 2. Crie uma nova branch seguindo o seguinte padrão de nomenclatura:
```bash
git checkout -b [nome-do-exercicio]-[seu-nome]
```
### Ex:
```bash
git checkout -b cinema-pablo
```

### 3. Navegue para sua pasta:
```bash
mkdir seu-nome (crie uma caso não exista)
cd seu-nome
```

### 4. Resolva os exercícios

IMPORTANTE: Faça um commit para cada questão resolvida.

Use mensagens de commit descritivas

### Exemplo de commits:
```bash
git add .
git commit -m "Questão 1 resolvida"

git add .
git commit -m "Questão 2 resolvida"
```

### 5. Faça o push:
#### Após resolver todas as questões:

```bash
git push
```
